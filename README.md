# Rusça Kelime Atölyesi

Rusça kelime oyunları ve gramer kuralları.

Site: https://themevias-arch.github.io/russianstudy/

## İçerik
- **Kurallar:** eril, dişil, nötr, -Ь ile biten isimler, çoğul kuralları, 7 harf kuralı, haftanın günleri
- **Kartlar:** kelime kartları (Rusça, okunuş, Türkçe)
- **Test:** kelime, cinsiyet ve çoğul testleri
- **Eşleştirme:** Rusça kelimeyi Türkçe karşılığıyla eşleştirme
- **Liste:** aranabilir kelime listesi

Kelimeler Resimli Kitap ve Resimsiz Kitap listelerinden alınmıştır.
